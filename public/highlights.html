Android Published SDK

ABC SDK

An android SDK published in Maven which can be used to display badge count in apps

ABC SDK (Android Badge Count) enables dynamic notification badging on Android app icons. Featuring a custom Gradle plugin, it generates badged adaptive icon layers at build time and leverages activity-aliases with PackageManager at runtime to seamlessly swap launcher icons without breaking user experience.
